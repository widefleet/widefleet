# Contributing to Widefleet

This directory documents work on Widefleet itself. App creators and installation operators use the [public documentation](https://widefleet.com/docs), whose source lives in `apps/docs/docs/`.

- [Development and checks](development.md): local setup, test fixtures and verification.
- [Architecture](architecture.md): internal components and implementation contracts; [runtime implementation notes](runtime-implementation.md) preserve native adapter investigations.
- [Control-plane experience](control-plane-experience.md): contributor UI guidance.
- [Container releases](container-releases.md), [CLI releases](cli-releases.md) and [runtime releases](runtime-releases.md): build, verify and publish platform artifacts.
- [Documentation website](documentation-site.md): local authoring, build, routing and publication.

The repository [contributor rules](../AGENTS.md#documentation-scope) define where new content belongs. Each topic has one canonical home; link to user-facing guides rather than keeping a second copy here.
