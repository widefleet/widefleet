**Open-source platform for agent-built apps and workflows.**

Widefleet runs your organization's internal apps. You or your coding agent create an
app with the CLI and deploy it with one command. Widefleet signs colleagues in with
their company account, gives each app its own database and file storage, and lets
you choose which groups can open it and which systems it can reach. Apps can offer
APIs to other apps and to AI clients through MCP.

Use Widefleet Cloud or run Widefleet on your own infrastructure. With self-hosting,
you manage identity configuration, updates and backups.
