Run the Widefleet platform in your own environment. Your team builds and deploys
apps; you operate management, the app runtime, identity integration, updates and
backups.

For a first look without company SSO or DNS configuration, use the
[local quickstart](/getting-started/quickstart).

## Requirements

- A Linux x86-64 host with Docker Engine 29.8.1 and Docker Compose 2.20.0 or newer.
  The host only needs Docker; the published images contain all runtime and setup tools.
- A management hostname and a separate app domain with DNS and HTTPS configured.
- PostgreSQL and object storage, either on the host or supplied by external services.
- Microsoft Entra, Google Workspace or another OpenID Connect provider for company sign-in.
- An operator responsible for updates, monitoring, backups and recovery.

## Install the platform

1. [Install Widefleet](/self-hosting/installation) on one host with the
   maintained Compose configuration, connect the deployment agent and deploy a
   first app.
2. Optionally use [external services and HTTPS](/self-hosting/external-services)
   for external PostgreSQL, cloud storage and automatic certificates, with
   [storage backends](/self-hosting/storage) for provider details.
3. [Set up company sign-in](/guides/company-sign-in) and review
   [sign-in and settings](/self-hosting/sign-in-and-settings).
4. Let employees and their agents connect with `widefleet login` alone through
   [company setup](/self-hosting/company-setup).

## Operate the installation

- [Versions and updates](/self-hosting/operations#versions-and-updates): update platform components and the app runtime together.
- [Backup and restore](/self-hosting/operations#back-up-and-restore): preserve and recover the complete installation.
- [Logs and troubleshooting](/self-hosting/operations#logs-and-troubleshooting): find the right logs for a failure.
- [Runtime logs](/self-hosting/runtime-logs): enable telemetry and investigate app failures.
- [Installation reporting](/self-hosting/installation-reporting): choose which usage insights to share.
