Widefleet is open source, and this roadmap outlines the capabilities we plan to
build on top of the platform. Scope and priorities may change with feedback;
there are no committed release dates.

## Product direction

### Company design and context

- Let IT define shared branding, design rules and components for company apps.
- Give coding agents access to company conventions and integration context
  across app projects.

### Business integrations

- Provide ready-to-use CRM, ERP and other business-system integrations built on
  the existing connector support.

### Identity and governance

- Synchronize company users and groups through SCIM.
- Let IT define policies that require approval for access to sensitive data
  and capabilities.

### Agent tooling and frameworks

- Expose platform administration through MCP, using the same permissions as
  the CLI, API and UI.
- Support additional app frameworks alongside SvelteKit.

### Security and maintenance

- Track dependency versions across apps and identify known vulnerabilities.
- Help administrators find affected apps and their maintainers, then use their
  coding agents to prepare updates across the app inventory.

### Self-hosting

- Expand to multiple runtime nodes with automatic capacity management.
- Add targeted backup and restore for individual apps.

## Releases

See [GitHub releases](https://github.com/widefleet/widefleet/releases) for shipped
versions and release notes. The [quickstart](/getting-started/quickstart) walks
